Ejercicio 1.1: Dos factores a la vez

¿Dependen los días para reabsorber la cola (Resorb.days) del depredador, de los recursos, o de ambos? Ajusta un ANOVA aditivo de dos vías y revisa la normalidad de los residuos.

  • Ejercicio
  • Pista
  • Solución
#| exercise: ex_1_1
boxplot(Resorb.days ~ Pred + Res, data = ranas)

aditivo <- aov(Resorb.days ~ Pred ____ Res, data = ranas)
summary(aditivo)

shapiro.test(residuals(____))

En un modelo aditivo, los factores se unen con +: cada uno tiene su propio efecto y los efectos se suman.

Solución. 

boxplot(Resorb.days ~ Pred + Res, data = ranas)

aditivo <- aov(Resorb.days ~ Pred + Res, data = ranas)

shapiro.test(residuals(aditivo))
gl SC CM \(F\) \(p\)
Pred 2 0.78 0.39 1.31 0.28
Res 1 4.35 4.35 14.53 0.0003
Residuales 74 22.14 0.30

Los recursos sí afectan el tiempo de reabsorción, el depredador no. Los residuos son normales (Shapiro-Wilk: \(p = 0.27\)). Con recursos bajos, la cola tarda en promedio medio día más en reabsorberse.

Ejercicio 1.2: ¿Es razonable el modelo aditivo?

El modelo aditivo supone que el efecto de los recursos es el mismo con cualquier depredador. Compruébalo con un gráfico de interacción y con un modelo que incluya la interacción.

  • Ejercicio
  • Pista
  • Solución
#| exercise: ex_1_2
interaction.plot(x.factor = ranas$Pred, trace.factor = ranas$____,
                 response = ranas$Resorb.days,
                 xlab = "Depredador", ylab = "Días para reabsorber la cola",
                 trace.label = "Recursos")

con_interaccion <- aov(Resorb.days ~ Pred ____ Res, data = ranas)
summary(con_interaccion)

Pred * Res es una abreviatura de Pred + Res + Pred:Res, donde Pred:Res es la interacción. En el gráfico, líneas más o menos paralelas indican que no hay interacción.

Solución. 

interaction.plot(x.factor = ranas$Pred, trace.factor = ranas$Res,
                 response = ranas$Resorb.days,
                 xlab = "Depredador", ylab = "Días para reabsorber la cola",
                 trace.label = "Recursos")

con_interaccion <- aov(Resorb.days ~ Pred * Res, data = ranas)
summary(con_interaccion)

Las líneas no son perfectamente paralelas, pero la interacción no es significativa (\(F = 0.86\), \(gl = 2\) y 72, \(p = 0.43\)): las diferencias que vemos son compatibles con el azar. El modelo aditivo del ejercicio 1.1 es razonable.

Ejercicio 2.2: Diagnósticos del modelo no aditivo

Revisa la normalidad de los residuos del modelo no_aditivo y la homogeneidad de varianzas entre las seis combinaciones de depredador y recursos.

  • Ejercicio
  • Pista
  • Solución
#| exercise: ex_2_2
no_aditivo <- aov(Age.FromEmergence ~ Pred * Res, data = ranas)

par(mfrow = c(2, 2))
plot(no_aditivo)
par(mfrow = c(1, 1))

shapiro.test(residuals(____))
bartlett.test(Age.FromEmergence ~ interaction(Pred, ____), data = ranas)

interaction(Pred, Res) crea un factor con las seis combinaciones (C.Hi, L.Hi, …), así bartlett.test() compara las varianzas de todas ellas.

Solución. 

no_aditivo <- aov(Age.FromEmergence ~ Pred * Res, data = ranas)

par(mfrow = c(2, 2))
plot(no_aditivo)
par(mfrow = c(1, 1))

shapiro.test(residuals(no_aditivo))
bartlett.test(Age.FromEmergence ~ interaction(Pred, Res), data = ranas)

Los dos supuestos fallan: los residuos no son normales (Shapiro-Wilk: \(p = 0.010\)) y las varianzas son muy distintas (Bartlett: \(p < 0.001\)). En el gráfico de residuos frente a ajustados, la dispersión crece con la media, en forma de embudo. Es una señal típica de que conviene transformar la respuesta con el logaritmo.

Ejercicio 2.3: La interacción que desaparece

Ajusta el mismo modelo con el logaritmo de la edad. ¿Mejoran los supuestos? ¿Sigue siendo significativa la interacción?

  • Ejercicio
  • Pista
  • Solución
#| exercise: ex_2_3
log_no_aditivo <- aov(____(Age.FromEmergence) ~ Pred * Res, data = ranas)
summary(log_no_aditivo)

shapiro.test(residuals(log_no_aditivo))
bartlett.test(log(Age.FromEmergence) ~ interaction(Pred, Res), data = ranas)

Puedes transformar la respuesta dentro de la fórmula: log(y) ~ A * B. En R, log() es el logaritmo natural.

Solución. 

log_no_aditivo <- aov(log(Age.FromEmergence) ~ Pred * Res, data = ranas)
summary(log_no_aditivo)

shapiro.test(residuals(log_no_aditivo))
bartlett.test(log(Age.FromEmergence) ~ interaction(Pred, Res), data = ranas)

Los supuestos mejoran mucho: los residuos ya son compatibles con la normalidad (Shapiro-Wilk: \(p = 0.10\)) y la diferencia entre varianzas es bastante menor (Bartlett: \(p = 0.022\), frente a \(p < 0.001\) antes). Y la interacción ya no es significativa (\(F = 1.47\), \(p = 0.24\)); depredador y recursos siguen siendo muy significativos (\(p < 0.001\)).

¿Qué pasó? En la escala logarítmica, los efectos se multiplican en lugar de sumarse. Con recursos bajos, la edad al salir del agua se multiplica por un factor que no difiere claramente entre depredadores; en días, un mismo factor se ve como un retraso mayor donde la edad ya era mayor. La “interacción” del ejercicio 2.1 era sobre todo un efecto de la escala. Moraleja: revisa los diagnósticos antes de interpretar una interacción.

Parte 3: Comparaciones múltiples y exportación

Ejercicio 3.1: Tukey con dos factores, y exportar a csv

Ajusta el modelo aditivo con el logaritmo de la edad y compara los depredadores con Tukey. Luego guarda la tabla del ANOVA en un archivo csv y vuelve a leerlo para comprobar que se guardó bien.

  • Ejercicio
  • Pista
  • Solución
#| exercise: ex_3_1
log_aditivo <- aov(log(Age.FromEmergence) ~ Pred + Res, data = ranas)
TukeyHSD(log_aditivo, which = "____")

tabla_anova <- as.data.frame(summary(log_aditivo)[[1]])
tabla_anova

write.csv(____, "tabla_anova.csv")
read.csv("____")

Con varios factores, which = "Pred" le dice a TukeyHSD() qué factor comparar. summary(modelo)[[1]] extrae la tabla del ANOVA; as.data.frame() la convierte en una tabla de datos que se puede exportar.

Solución. 

log_aditivo <- aov(log(Age.FromEmergence) ~ Pred + Res, data = ranas)
TukeyHSD(log_aditivo, which = "Pred")

tabla_anova <- as.data.frame(summary(log_aditivo)[[1]])
tabla_anova

write.csv(tabla_anova, "tabla_anova.csv")
read.csv("tabla_anova.csv")

En escala logarítmica, la diferencia L - C es -0.77 (\(p < 0.001\)), NL - C es -0.27 (\(p = 0.26\)) y NL - L es 0.50 (\(p = 0.011\)). Para interpretarlas, vuelve a la escala original con exp(): con el depredador letal, la edad al salir del agua es exp(-0.77) \(\approx\) 0.46 veces la del control, es decir, un 54% menor.

write.csv() guarda el archivo en la carpeta de trabajo (en tu computador, la de tu proyecto de R). Al leerlo, los nombres de las filas aparecen en una columna X; para recuperarlos como nombres de filas, usa read.csv("tabla_anova.csv", row.names = 1).

Ejercicio 4.1: ¿Hace falta la interacción?

Ajusta SVL.final ~ Pred * Res. Si la interacción no es significativa, ajusta el modelo aditivo e interpreta los efectos principales.

  • Ejercicio
  • Pista
  • Solución
#| exercise: ex_4_1
con_interaccion <- aov(SVL.final ~ Pred ____ Res, data = ranas)
summary(con_interaccion)

aditivo <- aov(SVL.final ~ Pred ____ Res, data = ranas)
summary(aditivo)

* incluye la interacción y + no. Si la interacción no aporta, el modelo más simple (aditivo) es más fácil de interpretar.

Solución. 

con_interaccion <- aov(SVL.final ~ Pred * Res, data = ranas)
summary(con_interaccion)

aditivo <- aov(SVL.final ~ Pred + Res, data = ranas)
summary(aditivo)

La interacción no es significativa (\(F = 0.37\), \(p = 0.69\)). En el modelo aditivo, el depredador tiene un efecto claro (\(F = 26.51\), \(p < 0.001\)) y los recursos no llegan a ser significativos (\(F = 2.95\), \(p = 0.09\)).
